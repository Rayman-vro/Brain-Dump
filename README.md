# Brain-Dump
Type a distracting thought, stash it, and get back to work. Notes are saved with timestamps in a timeline.

# Built with

- HTML
- CSS
- JavaScript

# Download

1. Download `index.html`, `styles.css`, and `script.js` into the same folder.
2. Open `index.html` in any modern browser.

Windows may show "Windows protected your PC" because the app is unsigned. Click "More info", then "Run anyway".

# How to use

1. Type a thought into the text box
2. Click "Stash Note" or press "Ctrl + Enter"
3. The note appears in the timeline with a timestamp, newest first
4. Click "Clear all" to delete every note

# Notes

- Notes stay on your device. Nothing is sent anywhere.
- Clearing your browser's site data will erase your notes.
- Notes are tied to the browser you use. They won't appear in a different browser or on another device.
